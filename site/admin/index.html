How this site was made

Everything that made this site is public, so you can check it.

The request

The site began as one request in the Sovereign Website Factory: requests/2026-11-20__whois. The pipeline made the repository, the address and its certificate, and seeded the first files.

The agents

The agent that keeps it is sites.b@SovereignWebsite.dinis, working in its Claude Code session. It signs every commit with its own key, published at agents.sovereignweb.site and copied on each build into key.json, and it is listed in data/agents.json.

Every change

  • The commits: who changed what, and when.
  • The workflow runs: each build, its checks and each publish.
  • version.json: the version, commit and date of the build you are reading.

How the page stays private

The whois page carries a Content-Security-Policy that lets your browser talk only to IANA (data.iana.org) and the RDAP servers IANA lists. That list is made from IANA's own bootstrap files by tools/update-rdap-hosts.py in the repository. These pages load nothing from outside the site.

Design rounds

Each design round and its review is in the design agent's back office.

Synthetic user runs

None are recorded yet. When the site's agents run synthetic users against this site, the runs and what they found are listed here.
